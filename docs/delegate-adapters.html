A flag de auto-aprovação muda por CLI. --dangerously-skip-permissions é real só para claude e agy. No opencode é --auto; no codex, -s workspace-write; no hermes, --yolo. O dispatcher usa a certa para cada runner — você não precisa lembrar.

delegate.sh

O dispatcher e suas variáveis

Um único script implementa o contrato e despacha para o CLI de DEVORQ_RUNNER. Wrappers finos (claude-delegate.sh, codex-delegate.sh, …) já fixam o runner — aponte DEVORQ_DELEGATE_FN para eles.

VariávelObrigatóriaDefaultO que faz
DEVORQ_RUNNERsim*—claude · codex · hermes · opencode · agy
DEVORQ_MODELnãodefault do CLIforça um modelo específico
DEVORQ_DELEGATE_TIMEOUTnão1800segundos até matar o runner
DEVORQ_DELEGATE_DRY_RUNnão01 = imprime o plano, não chama o LLM

* opcional se você usar um wrapper por runner, que já define DEVORQ_RUNNER.

O que o loop garante em volta do adapter: no-diff guard (delegate que não muda nada não vira done), stop-criteria (story falha sai da fila após 2 tentativas), commit por story com scan de segredos, e modo headless-safe (DEVORQ_AUTO_YES=1). O gate ainda não valida os acceptance criteria — quem garante trabalho real é o no-diff guard.

Como aplicar

Casos de uso

Overnight com spec pronta

Dev experiente, prd.json pronto → implementa em lote.

# commita cada story
export DEVORQ_DELEGATE_FN=…/codex-delegate.sh
export DEVORQ_AUTO_COMMIT=1
devorq auto --all

Testar sem gastar tokens

Valida contrato e dispatch — sem chamar o LLM.

export DEVORQ_RUNNER=hermes
export DEVORQ_DELEGATE_DRY_RUN=1
devorq auto # imprime o plano

Forçar um modelo

Troca o modelo default do runner.

export DEVORQ_RUNNER=claude
export DEVORQ_MODEL=opus
# codex: gpt-5.5 · opencode: minimax/…

CI / cron (headless)

Zero prompts interativos, não bloqueia sem test runner.

export DEVORQ_AUTO_YES=1
export DEVORQ_AUTO_ALLOW_NO_RUNNER=1
bash loop-auto.sh "$PWD" --all </dev/null

Debug de um adapter

Uma iteração e acompanha o journal.

bash loop-auto.sh "$PWD" 1
tail -f "$PWD/.devorq-auto/runs/"*.log

Runner próprio

Qualquer CLI: envolva no contrato de 3 linhas.

my_delegate(){ # $1=json $2=dir
  ( cd "$2" && meu-cli --yes "$1" ); }
export DEVORQ_DELEGATE_FN=my_delegate
