# DEVORQ v4.1.0 — Loop Engineering experimental

**Data:** 2026-07-13

## Destaques

- Novo `devorq loop implementation --experimental` com contrato de executor existente, verificador e juiz determinístico.
- Contratos JSON Schema v1, migração de PRD sem mutar a entrada e evidência com hash por run.
- AUTO e code review passam a falhar de modo explícito quando não há condição verificável de sucesso.

## Compatibilidade

Não há remoção de `devorq auto`, `DEVORQ_DELEGATE_FN` ou adapters. O perfil novo é opt-in e os demais loops continuam indisponíveis por design.

## Validação

As suítes de contratos, migração, AUTO, review e loop passaram; o cenário Playwright de modos passou 8/8.
